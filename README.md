# TaskTrek – Smart To-Do & Goal Planner

A beginner-friendly student productivity web project built with HTML, CSS, and JavaScript.

## Features
- Add tasks with category, priority, and optional due date
- Mark tasks complete and delete them
- Filter all, pending, and completed tasks
- View live task statistics and completion progress
- Dark mode and responsive layout
- Browser localStorage persistence (no account or cloud sync)

## Run locally
Open `index.html` in a modern browser. No installation or server required.

## Deploy with GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save. GitHub will provide the live URL once deployed.

## Project structure
- `index.html`: page structure
- `style.css`: design and responsive styling
- `script.js`: task logic and browser storage

This is a front-end prototype, not a multi-user SaaS backend.
